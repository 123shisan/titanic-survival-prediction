# 泰坦尼克号生存预测

从零完成的第一个机器学习项目：根据乘客信息预测泰坦尼克号事故中是否存活。

## 项目结构

```
titanic/
├── train.csv              # 数据（1000名乘客）
├── step3_features.py      # 第三步：特征处理（文字→数字）
├── step4_train.py         # 第四步：训练逻辑回归
├── step5_compare.py       # 第五步：逻辑回归 vs 随机森林
├── step6_crossval.py      # 第六步：交叉验证科学评估
├── step7_feature_eng.py   # 第七步：特征工程（FamilySize）
├── step8_binning.py       # 第八步：年龄分箱
├── step9_save_model.py    # 第九步：训练最终模型并保存
├── predict.py             # 预测演示：输入乘客信息→预测生死
└── model.pkl              # 训练好的模型文件
```

## 快速开始

```bash
# 1. 安装依赖
pip install pandas scikit-learn joblib

# 2. 训练并保存模型
python step9_save_model.py

# 3. 预测演示
python predict.py
```

## 模型与结果

- **模型**：逻辑回归（LogisticRegression）
- **准确率**：5折交叉验证平均 **73.3%**
- **关键特征**：性别（女性生存率高）、舱等（头等舱生存率高）、年龄（儿童生存率高）

### 对比实验记录

| 实验 | 准确率 | 结论 |
|---|---|---|
| 逻辑回归 | 73.3% | 最终选择 |
| 随机森林 | 68.1% | 数据量小，过拟合，弃用 |
| 加 FamilySize 特征 | 73.3% | 无提升，弃用 |
| 年龄分箱 | 72.9% | 无提升，弃用 |

## 核心知识点

- **特征/标签**：特征是输入，标签是答案
- **训练**：`model.fit()` 让机器自动调权重
- **过拟合**：模型把噪音当规律背下来，用交叉验证检测
- **交叉验证**：数据切5份轮流测试取平均，科学评估模型
- **特征工程**：手动造新特征帮模型看清规律（本例无显著提升）

## 复现结果

固定随机种子，结果可复现。数据为模拟数据，结构与真实 Kaggle 泰坦尼克数据一致。
